# Что класть в эту папку

Выгрузки из YouTube Studio. Софт их прочитает и начнёт учиться
на ВАШИХ роликах, а не только на чужих каналах.

## 1. Удержание — самое ценное

YouTube Studio → **Аналитика** → вкладка **Вовлечение**
→ выбрать ролик → **Удержание аудитории**
→ справа вверху кнопка **⤓ Экспорт** → **Значения, разделённые
запятыми (.csv)**

Даёт кривую: какая доля зрителей осталась на каждой секунде.
Именно она показывает, ГДЕ они уходят.

Кладите по одному файлу на ролик. Имя не важно.

## 2. Обзор по всем роликам

YouTube Studio → **Аналитика** → **Контент**
→ период **За всё время** → **⤓ Экспорт** → CSV

Даёт по каждому ролику: просмотры, CTR обложки, среднюю
длительность просмотра, подписки. Отсюда видно, какие
заголовки и обложки кликают.

## 3. Источники трафика (если не сложно)

Там же, вкладка **Охват** → **⤓ Экспорт**.

## Как часто

Раз в неделю. Чаще не нужно: цифры за сутки шумные и уводят
в ложные выводы.

## Чего НЕ нужно

Скриншоты. С картинки я прочитаю только грубые провалы, а из
CSV — точные секунды.
