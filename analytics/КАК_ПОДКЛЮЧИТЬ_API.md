# Как подключить статистику YouTube — от и до

Делается ОДИН РАЗ. Дальше цифры тянутся сами.

Всё, что ниже, делаете вы: Google отдаёт статистику канала только
владельцу, и вход в аккаунт за вас никто выполнить не может.

---

## Шаг 1. Завести проект

1. Откройте `console.cloud.google.com`
2. Войдите тем аккаунтом, **на котором заведены каналы**. Это важно:
   статистику отдадут только владельцу.
3. Вверху слева, рядом с надписью «Google Cloud», нажмите на
   переключатель проектов → **New Project**
4. Название любое, например `content-factory`. → **Create**
5. Дождитесь, пока проект создастся, и **переключитесь на него** тем же
   списком вверху. Дальше всё делается внутри него.

---

## Шаг 2. Включить два интерфейса

Меню слева (три полоски) → **APIs & Services** → **Library**

Найти через поиск и на каждом нажать **Enable**:

- **YouTube Analytics API** — удержание, CTR, просмотры
- **YouTube Data API v3** — список роликов и их названия

Оба обязательны. Первый без второго не поймёт, о каком ролике речь.

---

## Шаг 3. Экран согласия (здесь чаще всего застревают)

**APIs & Services** → **OAuth consent screen**

1. Тип: **External** → **Create**
   (Internal доступен только организациям Google Workspace.)
2. Заполнить обязательное:
   - App name: `content-factory`
   - User support email: ваша почта
   - Developer contact information: та же почта
   → **Save and Continue**
3. **Scopes** — ничего не добавляйте, просто **Save and Continue**
4. **Test users** → **Add users** → впишите **свою же почту**, ту, на
   которой каналы.

   ЭТОТ ПУНКТ ПРОПУСКАТЬ НЕЛЬЗЯ. Пока приложение в режиме Testing,
   вход разрешён только перечисленным здесь. Без него на последнем шаге
   вы получите «доступ заблокирован».

   → **Save and Continue** → **Back to Dashboard**

---

## Шаг 4. Получить ключ доступа

**APIs & Services** → **Credentials** → вверху **+ Create Credentials**
→ **OAuth client ID**

- Application type: **Desktop app**
- Name: любое
- → **Create**

Появится окно с идентификатором. Нажмите **DOWNLOAD JSON**.

---

## Шаг 5. Положить файл

Скачанный файл называется примерно
`client_secret_1234-abcd.apps.googleusercontent.com.json`

Положите его сюда:

    C:\Users\ali\Desktop\2\analytics\

Переименовывать не нужно.

**Этот файл — ключ от вашей статистики.** Он в .gitignore и в публичный
репозиторий не уедет. Никому его не пересылайте.

---

## Шаг 6. Сказать мне

Напишите, что файл на месте. Дальше я:

1. напишу подключение;
2. запущу его один раз — откроется браузер, вы **сами** выберете свой
   аккаунт и нажмёте «Разрешить». Пароль ввожу не я и не вижу его;
3. после этого рядом ляжет `token.json`, и вход больше не потребуется —
   ни при перезапуске, ни через месяц.

---

## Что будет дальше

Софт начнёт тянуть по каждому вашему ролику:

- **кривую удержания посекундно** — где именно уходят зрители;
- **CTR обложки** — какая доля увидевших нажала;
- среднюю длительность просмотра, подписки с ролика, источники трафика.

И применять это:

- ставить графику туда, где удержание падает у ВАС, а не по общим
  правилам жанра;
- сверять длину роликов с тем, до какой минуты вас реально досматривают;
- отбирать формулы заголовков и обложек по вашему CTR, а не только по
  чужим каналам.

Сейчас софт учится на референсах ниши — на чужих каналах. О ваших
зрителях он не знает ничего.

---

## Если что-то пошло не так

**«Доступ заблокирован: приложение не прошло проверку»** — не добавили
себя в Test users (шаг 3, пункт 4).

**«API не включён»** — не нажали Enable на обоих интерфейсах (шаг 2)
или включили их в другом проекте.

**Пусто по всем роликам** — вошли не тем аккаунтом. Нужен тот, где
каналы, а не тот, где заводили проект, если это разные.

**Квота** — бесплатных обращений хватает с большим запасом: статистика
тянется раз в сутки, а не на каждый ролик.
