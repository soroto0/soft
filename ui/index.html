Проект

Одна кнопка проходит весь путь: озвучка → субтитры → кадры → рендер

С «Разнообразием» голос, темп, стиль субтитров, цветокор и монтаж выбираются случайно под каждый проект — ролики канала не похожи друг на друга (снижает риск флага «inauthentic content»).
Пройдёт по всем каналам и соберёт ролик на каждый — той же цепочкой, что и кнопка выше. Тема берётся по нише канала, каждый ролик уходит в свою папку с датой. Упавший канал не останавливает остальные; итог — последними строками журнала. Оставь ноутбук включённым.
Пустое поле — значит ВСЕ включённые каналы разом. Каждый канал идёт своим процессом, поэтому они не мешают друг другу форматом кадра и кнопкой «Стоп». Пока один ждёт ответа сервера, второй жмёт видео — на сборке ffmpeg занят лишь треть времени. Журналы: autopilot_logs/<канал>.log. Идёт снаружи окна: программу не закрывай.

Озвучка

Голос, музыка и звуки быта

Движок озвучки
«Глубокий голос» — компрессия + нижние частоты + нормализация, как у диктора документального фильма.
Фоновая музыка
Несколько треков склеиваются в плейлист и зацикливаются под всю длину видео. «Подобрать под жанр» берёт трек сам из библиотеки в Настройках. Музыка должна быть лицензионной.
ASMR-звуки быта
Софт сам раскидывает короткие звуки быта по таймлайну тихо под голосом. Скачать бесплатно: pixabay.com/sound-effects.

Раскадровка

Кадры под каждую фразу: стоки, свои файлы или генерация ИИ

«Свои фото/видео» копируются в проект и идут в рендер вперемешку со стоками (фото автоматически оживают зумом Ken Burns).
Сборка по субтитрам
«Только стоки» почти не генерирует ИИ-кадры. «Микс» намеренно генерирует заданную долю планов через ИИ равномерно по ролику — так видео не выглядит сплошным стоком. «ИИ в едином стиле» генерирует всё: медленно, зато цельно.

ИИ-видео

Все режимы генератора напрямую — без сценария и без Remotion

Шаг 1 — сгенерировать кадры
Кадры появятся в списке ниже. Отметь нужные галочками и нажми «Собрать из выбранных» — соседние кадры сшиваются в клип, поэтому из N кадров выходит N−1 клипов по 8 секунд. Длину клипа генератор не принимает: замер — заказал 4 с, вернулось 8,0.
Ингредиенты 0
Прикладываются автоматически ко всему, что генерируется здесь — выбирать их каждый раз не нужно. Пустой набор = каждый клип сам по себе, герой будет разным.

Озвучка, субтитры и клип под каждый план. Рендера и плашек не будет — режешь сам.
Что лежит в проекте
Remotion и собранный ролик для ручного монтажа не нужны. Нажми на строку — покажу файл в проводнике.
Как открыть в Premiere Pro
1. File → Import → sequence.xml — появится готовая секвенция: клипы стоят по таймкодам, под ними дорожка с озвучкой.
2. File → Import → voiceover.srt, перетащи на таймлайн — получишь дорожку подписей.
3. Папку storyboard до импорта не перемещай: пути к клипам внутри sequence.xml записаны полностью.
