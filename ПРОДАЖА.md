# Шпаргалка: запуск и продажа

## Как запускается софт

**У тебя** — ярлык `Content Factory` на рабочем столе. Он идёт напрямую:
системный `pythonw.exe` → `webapp.py`. Минуя мастер установки.

**У покупателя** — иначе, и это важно помнить, когда он пишет «не работает»:

```
КонтентФабрика — ПОЛНАЯ.exe     установщик
  └─ Запустить.bat
       └─ setup\setup.ps1        ← проверяет Python, FFmpeg, Node,
            │                       ставит .venv, спрашивает ключи
            └─ pythonw webapp.py
                 ├─ окно активации (спросит ключ)
                 └─ окно программы
```

Полезные флаги: `Запустить.bat -Reconfigure` — заново пройти мастер ключей.

**Проверять надо через `Запустить.bat`**, а не через свой ярлык: покупатель
пойдёт этим путём, и ломается обычно там.

---

## Что именно ты продаёшь

Не «программу», а **готовую студию под ключ**: тема → сценарий → озвучка →
видеоряд → субтитры → графика → mp4 на 15 минут. Один человек с ней делает
за вечер то, на что уходит неделя.

Материальная часть — установщик на 3,3 МБ (`КонтентФабрика — ПОЛНАЯ.exe`) плюс
ключ. Демоверсия — тот же файл с пометкой ДЕМО, три ролика с надписью на кадре.

---

## Собрать свежий установщик

```bash
powershell -ExecutionPolicy Bypass -File setup\build_installers.ps1
```

Соберёт обе редакции — ПОЛНУЮ и ДЕМО. Внутрь попадают только файлы из белого
списка: ни `licensing\`, ни твоих ключей, ни каналов, ни готовых роликов.
Проверено.

## Продажа по шагам

### Вариант «Навсегда» — 180 000 ₸, сервер не нужен

1. Отправляешь **демо** и ссылку на ролик.
2. Человек ставит, смотрит, решает.
3. Оплата Kaspi.
4. Он присылает **код своего компьютера** — программа показывает его в окне
   активации, оттуда его можно скопировать.
5. Ты выписываешь ключ:

```bash
python licensing/admin.py offline 5c1c55fc3ff2a653 --note "Ерлан, Kaspi 180000"
```

6. Отправляешь получившуюся строку. Всё, он вставляет и работает.

### Вариант «Подписка» — 12 000 ₸/мес, нужен живой сервер

```bash
python licensing/admin.py sell месяц --note "Айдос, Kaspi 12000"
```

Даёт короткий `KF-79ZT-CN5C-3Y4X` — отправляешь сразу, кода машины не нужно.
Но сервер должен работать постоянно, иначе программа встанет у всех
подписчиков.

**Пока сервер не на VPS — продавай «Навсегда».**

## Каждый день

```bash
python licensing/admin.py list          # кто что купил, у кого кончается
python licensing/admin.py extend KF-... --days 30
python licensing/admin.py revoke KF-... # вернул деньги
python licensing/admin.py reset-devices KF-...   # сменил компьютер
```

---

## Что нельзя терять

`licensing/owner_key.pem` — им подписаны все бессрочные лицензии.
`licensing/licenses.db` — вся твоя бухгалтерия: кто, что, за сколько.

Скопируй оба на флешку прямо сейчас. Ни то, ни другое не уезжает покупателю и
не попадает на GitHub — проверено, но от потери это не спасает.
