* **Название приёма:** Разворачивание линии в плашку-кнопку (*Line expand to pill*) с последующим пружинным кликом (*Squash & Stretch Punch*).
* **Числа:** 
  * Рост линии в ширину: **0.15–0.2 с** (от 0% до 100% ширины).
  * Раскрытие по высоте в плашку: **0.15 с** (толщина от 2–4 px до 50–60 px с радиусом скругления 50%).
  * Клик/отскок: сжатие по масштабу до **90–92%** за **0.06–0.08 с** (2 кадра при 30 fps), перелёт цели на **+5%** (до 105%) и затухание за **0.15–0.2 с** (ровно **1 колебание**).
* **Кривая:** 
  * Раскрытие формы — резкий старт с мягким торможением (*Fast In, Soft Ease Out*).
  * Реакция на клик — резкий спад (*Ease-in* в сжатие) $\to$ пружинный отскок с перелётом (*Overshoot*) $\to$ возврат в исходный масштаб.
* **Как повторить в Remotion:**
  ```tsx
  // 1. Раскрытие плашки (30 fps)
  const width = interpolate(frame, [0, 6], [0, 300], {
    extrapolateLeft: 'clamp',
    extrapolateRight: 'clamp',
    easing: Easing.out(Easing.cubic),
  });
  const height = interpolate(frame, [6, 11], [4, 54], {
    extrapolateLeft: 'clamp',
    extrapolateRight: 'clamp',
    easing: Easing.out(Easing.quad),
  });

  // 2. Отскок кнопки при клике на clickFrame
  const clickScale = spring({
    frame: frame - clickFrame,
    fps: 30,
    from: 0.92,
    to: 1,
    config: { damping: 11, stiffness: 240, mass: 0.6 },
  });
  ```
* **На чём уместен:** CTA-кнопки (подписка, переход), плашки с ключевыми метриками/числами, всплывающие подписи, акцентные плашки в схемах.

1. **Название приёма:** 
**Sonar Pulse / Радиальный импульс (расширяющиеся затухающие кольца).** 
Создаёт эффект эхолокации/радара: из центральной точки последовательно рождаются концентрические окружности, которые увеличиваются в диаметре со спадом прозрачности (fade-out) до полного растворения.

2. **Числа:**
* **Длительность одного импульса:** `0.8–1.0 сек` (24–30 кадров при 30 fps).
* **Масштаб (Scale):** от `0%` (или `10%`) в точке излучения до `300–350%` (увеличение в 3–3.5 раза).
* **Прозрачность (Opacity):** старт на `0.8–1.0` (100%), линейное или кубическое угасание до `0` на `100%` пути.
* **Периодичность повтора:** рождение новой волны со сдвигом каждые `0.25–0.35 сек` (всего 3–4 одновременных кольца).
* **Колебания/перелёт:** без перелёта и отдачи (чистое расширение вовне).

3. **Кривая:**
* **Ease-Out (замедление к концу):** быстрое расширение на старте и плавное рассеивание при достижении максимального радиуса (кривая Безье: `cubic-bezier(0.16, 1, 0.3, 1)`).

4. **Реализация в Remotion:**
```tsx
import { interpolate, useCurrentFrame } from "remotion";

const frame = useCurrentFrame();
const duration = 25; // длительность 1 импульса в кадрах
const delay = 8;     // смещение следующей волны

// Для одной волны с учётом задержки:
const progress = interpolate(
  (frame - delay) % duration, 
  [0, duration], 
  [0, 1], 
  { extrapolateLeft: "clamp", extrapolateRight: "clamp" }
);

const scale = interpolate(progress, [0, 1], [0.2, 3.2]);
const opacity = interpolate(progress, [0, 0.2, 1], [0, 0.9, 0]);

// Стили объекта:
// transform: `scale(${scale})`, opacity, borderRadius: '50%', border: '2px solid cyan'
```

5. **Где уместен приём:**
* **Схемы и карты:** радары, зоны покрытия сети, GPS-маячки, эпицентры событий.
* **Инфографика:** фокус внимания на ключевой точке или маркере.
* **Подписи/иконки:** пульсация кнопки действия (CTA) или индикатор микрофона/звука.

const itemY = interpolate(frame, [20, 28], [15, 0], {

### Разбор приёма: **Pop-in с овершутом (Elastic Scale Pop)**

1. **Название приёма и действие:**
   * **Scale Overshoot (Пружинное появление).** Объект мгновенно вырастает из точки (`scale: 0` $\to$ `scale: 1`), проскакивает целевой размер, слегка сжимается обратно и фиксируется на 100%.

2. **Числа:**
   * **Длительность:** 0.35–0.40 сек (10–12 кадров при 30 fps).
   * **Перелёт цели (Overshoot):** +15–20% (масштаб доходит до 115–120%).
   * **Амплитуда отскока назад:** -5% (сжатие до 95%).
   * **Количество колебаний:** 1.5 фазы (0% $\to$ 118% $\to$ 96% $\to$ 100%).

3. **Кривая движения:**
   * **0–40% времени:** Агрессивное ускорение от нуля вверх.
   * **40–65% времени:** Пробитие целевой точки с резким торможением на пике (1.18x).
   * **65–85% времени:** Быстрый возврат со сжатием чуть ниже нормы (0.96x).
   * **85–100% времени:** Плавное затухание в исходный размер (1.0x).

4. **Как повторить в Remotion:**

   * **Через `spring` (рекомендуемый):**
   ```tsx
   const scale = spring({
     frame,
     fps,
     config: {
       mass: 0.5,       // легкий объект, резкий старт
       stiffness: 190,  // сильная жесткость для быстрого вылета
       damping: 11,     // дает ровно 1 заметный перелет и мягкую посадку
     },
   });
   // Стили: transform: `scale(${scale})`
   ```

   * **Через `interpolate` (по ключевым кадрам на 30 fps):**
   ```tsx
   const scale = interpolate(
     frame,
     [0, 6, 9, 12],
     [0, 1.18, 0.96, 1.0],
     { extrapolateRight: "clamp" }
   );
   ```

5. **На чём приём уместен:**
   * **Иконки и маркеры внимания:** знак вопроса, эмодзи, восклицательные знаки (как на 00:12–00:16).
   * **Указатели и стрелки:** всплывающие метки направлений («GEWICHT» / вес).
   * **Короткие бейджи и плашки:** теги с названиями элементов конструкции.

   * **Общая длительность появления:** 0.6–0.7 сек (18–20 кадров при 30 fps).
   * **Прорисовка окружности (`Trim Paths`):** от 0% до 100% длины контура за 0.45 сек (14 кадров), вращение на 90°–180°.
   * **Прорисовка линии:** от 0% до 100% за 0.35 сек (с задержкой 4 кадра).

   const circleRotate = interpolate(frame, [0, 14], [-90, 45], { extrapolateRight: "clamp" });

3) **Кривая**:
   - Функция плавности: `easeInOut`.
   - Линейное или плавное ускорение без отскока/перелёта за цель (интерполяция по точкам массивов `inputRange` и `outputRange`).

4) **Реализация в Remotion (через `interpolate`)**:
   ```tsx
   const frame = useCurrentFrame();
   const progress = interpolate(frame, [0, 30], [0, 2], {
     extrapolateRight: 'clamp',
   });
   const path = interpolatePaths(progress, [0, 1, 2], [path1, path2, path3]);
   ```
   *(Где `[0, 30]` — кадры для 0.5 сек при 60fps).*

5) **Уместность**: Иконки, логотипы, векторные иллюстрации, переключение интерфейсных состояний (например, анимация иконки «гамбургер» в «крестик»).
