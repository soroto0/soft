# Контент-фабрика

Конвейер, который делает документальный YouTube-ролик почти целиком сам:
придумывает тему с оглядкой на то, что сейчас смотрят в нише, пишет сценарий,
озвучивает, подбирает видеоряд (стоки + сгенерированные ИИ кадры), ставит
субтитры и моушн-графику, накладывает цветокор и звук — и отдаёт готовый файл.

Работает окном на Windows: запустил, нажал, ждёшь.

---

## Коротко: что нужно, чтобы начать

| Что | Зачем | Обязательно? |
|---|---|---|
| Windows 10/11 | приложение открывается окном, пути и шрифты — виндовые | да |
| Python 3.10+ | весь конвейер | да |
| FFmpeg | склейка, звук, цветокор | да |
| Node.js 18+ | моушн-графика Remotion | нет, но заметно лучше с ним |
| Ключ Google Gemini | тексты: сценарий, сцены, SEO | да |
| Ключ Pexels | видеоряд из стоков | да |
| Остальные ключи | ИИ-видео, музыка, разбор ниши | нет, см. таблицу ниже |
| ~10 ГБ на диске | окружение Python (2 ГБ), Remotion (0.7 ГБ), сами ролики | да |

## Запуск

1. Распакуй папку куда угодно (лучше без пробелов и кириллицы в пути).
2. Двойной клик по **`Запустить.bat`**.

Дальше скрипт всё делает сам: проверяет Python, FFmpeg и Node, создаёт
отдельное окружение `.venv`, ставит зависимости, ставит пакеты Remotion,
создаёт `.env` и по одному спрашивает ключи. В конце открывается окно
приложения.

**Первый запуск долгий: 15–30 минут** — качается около 3 ГБ (одно только
распознавание речи тянет `torch`). Все следующие запуски — секунды: скрипт
видит, что всё уже стоит, и сразу открывает окно.

Чего ждать, если чего-то не хватает:

- нет Python или FFmpeg — скрипт напишет точную команду `winget` и
  остановится; это единственные два обязательных условия;
- нет Node.js — работать будет, но моушн-графику нарисует встроенный
  движок: проще и менее эффектно;
- не заданы ключи — окно откроется, но генерация упадёт с внятным
  сообщением, какого ключа не хватило.

Полезные флаги (из командной строки в папке проекта):

```
Запустить.bat -Reconfigure   # заново пройти мастер ключей
Запустить.bat -SkipLaunch    # только настроить окружение, окно не открывать
```

## Ключи

Мастер при первом запуске проведёт по этому же списку и подскажет ссылки.
Любой ключ можно вписать позже — руками в файл `.env` в папке проекта.

### Обязательные

| Ключ | Зачем | Где взять | Цена |
|---|---|---|---|
| `GEMINI_API_KEY` | тексты: черновик сценария, разбивка на сцены, поисковые запросы, SEO | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) | бесплатно |
| `PEXELS_API_KEY` | видео и фото для сцен | [pexels.com/api](https://www.pexels.com/api/) | бесплатно |

Без Gemini текст писать нечем и конвейер не стартует. Без источника картинки
нечем заполнять сцены. Формально Gemini заменяется на `AGNES_API_KEY`, а
Pexels — на связку `VEO_API_KEY` + `AGNES_API_KEY` (тогда весь видеоряд
генерируется ИИ), но самый дешёвый рабочий минимум — именно эти два.

**Про квоту Gemini.** Она считается на пару «проект + модель», а не на ключ, и
на бесплатном тарифе кончается быстро — примерно два десятка запросов в сутки.
Код умеет перебирать несколько ключей: допиши в `.env` строки
`GEMINI_API_KEY2=`, `GEMINI_API_KEY3=` и так далее — они подхватятся сами.
Так же устроены `VEO_API_KEY2...` и `AGNES_API_KEY2...`.

### Желательные

| Ключ | Что даёт | Без него | Цена |
|---|---|---|---|
| `PIXABAY_API_KEY` | второй сток | материал однообразнее, чаще повторы | бесплатно |
| `VEO_API_KEY` | ИИ-видео Veo и ИИ-картинки | только сток и оживление фото «Ken Burns» | платно, подписка [veononstop.org](https://veononstop.org) |
| `AGNES_API_KEY` | ИИ-картинки, запасной канал для текстов | картинки уйдут на Gemini, запасного канала не будет | платно |
| `YOUTUBE_API_KEY` | разбор ниши перед роликом: что в теме уже заходит | тему придётся придумывать вручную, без опоры на свежие данные | бесплатно |

### По желанию

| Ключ | Что даёт | Без него |
|---|---|---|
| `JAMENDO_CLIENT_ID` | фоновая музыка по лицензии | подбор музыки пропускается; можно указать свою папку в настройках |
| `AWS_ACCESS_KEY_ID` + `AWS_SECRET_ACCESS_KEY` | озвучка Amazon Polly | озвучивает бесплатный Edge TTS — большинству этого хватает |

## Сколько это стоит и сколько идёт

Оценки грубые: всё зависит от длины ролика и доли ИИ-кадров.

**Полностью бесплатный набор** (Gemini + Pexels + Edge TTS): ролик на 10–13
минут собирается примерно за **40–90 минут**. Денег — ноль. Видеоряд целиком
стоковый, поэтому кадр не всегда точно ложится на фразу.

**С ИИ-видео** (добавлен `VEO_API_KEY`): те же 10–13 минут собираются
**2–5 часов** — генерация видео идёт через очередь на стороне сервиса, и это
самое узкое место. Зато кадр соответствует тексту по построению, а не по
совпадению ключевого слова. Стоимость — по подписке сервиса.

Что занимает время, по убыванию: генерация ИИ-видео → распознавание речи для
субтитров → рендер моушн-графики → склейка ffmpeg.

Заметное ускорение: в `.env` поставить `VEO_FAST_MODE=1` (ИИ-видео только на
ключевые сцены, остальные ИИ-кадры оживляются локально) и `VEO_UPSCALE=0`
(черновик в 720p вместо апскейла до 1080p).

Есть ночной режим: приложение берёт задачу и ведёт её до утра само, не
начиная ролик, который заведомо не успеет закончить.

## Звуковые эффекты

В раздаче нет папки `assets/`: звуки в ней под чужой лицензией, передавать их
дальше нельзя. Своя библиотека собирается одной командой:

```
.venv\Scripts\python sfx_library.py --fetch
```

Качает подборку из коллекций Internet Archive под **CC0** (общественное
достояние: коммерческое использование без атрибуции, ключ не нужен).
Лицензии `NC` и `ND` намеренно не берутся — они запрещают монетизацию и
переработку, а на канале с рекламой это прямой риск.

Пока библиотеки нет, рендер обходится тремя синтезированными звуками: ролик
соберётся, но звуковой ряд будет однообразным.

## Каналы

Настройки канала — язык, тон, длительность, голос, палитра цветокора, стиль
субтитров, доля ИИ-кадров — живут в `channels.json`. В раздаче его нет: там
рабочие данные автора (темы, счётчики серий, заметки о конкурентах).

Рядом лежит `channels.example.json` — скопируй его в `channels.json` и
поправь под себя либо заведи канал прямо в окне приложения.

Каждый канал держит свой почерк намеренно: свои палитры монтажа, свой набор
звуков, свой шрифт субтитров. Иначе разные каналы выглядят одинаково, а
субтитры — самый заметный элемент на экране.

Почерк задаёт поле **`palette`**, и это единственная настройка канала, которой
нет в форме: её правят прямо в `channels.json`. Значения — `harsh`, `warm`,
`contemplative`. По ней разведены склейки и движение кадра, воздух кадра, звук
и вид плашек. Пустая `palette` — не «нейтрально», а «общий пул с общими
весами»: два канала с пустой палитрой снимут похожие ролики.

### Откуда берутся плашки

Библиотеки плашек в раздаче нет, и это не урезанная версия — так устроен
продукт. Плашки закреплены за каналом: `overlays._library_variants` сверяет
метку канала строго, поэтому чужая библиотека новому каналу всё равно не
досталась бы ни одной записью.

Свою канал получает сам и сразу. На первой же сборке ролика
`variant_factory.ensure` заводит **8 видов на каждый из 18 типов — 144 своих
плашки**, механически: без ИИ, без единого платного вызова, за доли секунды.
Вид собирается из словаря приёмов канала (`remotion/src/variants/_look.ts`):
своё место в кадре, своя подложка, своя техника появления, свой шрифт.

Дальше библиотека растёт вторым, «дорогим» способом: ИИ пишет по одному
новому компоненту на ролик — штучные виды, которых нет больше ни у кого.

**Обязательное условие: у канала должна быть заполнена `palette`.** Без неё
фабрика напишет в журнал «нет известной палитры — добавлять нечего» и не
заведёт ни одной плашки: канал останется на восьми встроенных видах из
`Overlay.tsx`. В `channels.example.json` палитра проставлена; если заводишь
канал через окно приложения — впиши её в `channels.json` руками, в форме
этого поля нет.

## Лицензии: что внутри и на каких правах

Программа почти ничего чужого в себе не несёт. Библиотеки Python и пакеты
Node **не входят в поставку** — их ставит на твою машину `pip` и `npm` при
первом запуске, и лицензионные отношения возникают у тебя с ними напрямую.
Ниже — то, что важно знать, если ролики монетизируются.

### Сторонние компоненты

| Компонент | Лицензия | Входит в поставку | Коммерческое использование |
|---|---|---|---|
| Шрифты Inter, Lora, Oswald | SIL OFL 1.1 | да, `remotion/public/fonts` | да, включая монетизацию |
| Remotion 4 (моушн-графика) | Remotion License | нет, ставит npm | **см. ниже — есть порог** |
| HyperFrames (второй движок плашек) | Apache-2.0 | нет, тянет npx | да |
| React, Tailwind, TypeScript | MIT | нет, ставит npm | да |
| requests, boto3, botocore | Apache-2.0 | нет, ставит pip | да |
| openai-whisper (субтитры) | MIT | нет, ставит pip | да |
| Pillow | MIT-CMU | нет, ставит pip | да |
| pywebview, python-dotenv | BSD-3-Clause | нет, ставит pip | да |
| PyTorch, NumPy | BSD / Apache-2.0 | нет, ставит pip | да |
| edge-tts (озвучка по умолчанию) | LGPL-3.0 | нет, ставит pip | да, но **см. ниже** |

Файлы лицензий на шрифты лежат рядом со шрифтами (`OFL-inter.txt`,
`OFL-lora.txt`, `OFL-oswald.txt`) — этого требует сама OFL, не удаляй их.
Шрифты можно встраивать в видео и продавать ролики; нельзя продавать сами
шрифты как шрифты.

### Remotion: порог по размеру компании

Remotion бесплатен для физлиц, некоммерческих организаций и компаний **до
трёх сотрудников включительно**. Компании от четырёх человек обязаны купить
Company License на [remotion.pro](https://www.remotion.pro/license). Это не
особенность этой программы — это условие самого Remotion, и обязательство
возникает у того, кто им пользуется, то есть у тебя.

Если платить не хочется, Remotion не обязателен: без Node.js плашки рисует
встроенный движок на Pillow. Проще на вид, но ролик собирается целиком.

### edge-tts: бесплатно, но не гарантировано

Озвучка по умолчанию идёт через `edge-tts`. Сама библиотека под LGPL-3.0 —
с ней всё в порядке. Вопрос в другом: она обращается к служебному голосовому
сервису Microsoft Edge, а это не публичный API с публичной офертой. Он может
измениться или закрыться без предупреждения, и условия Microsoft такое
использование прямо не разрешают.

Для личных роликов этим обычно пренебрегают. Если строишь на этом бизнес —
переключись на Amazon Polly (`AWS_ACCESS_KEY_ID` + `AWS_SECRET_ACCESS_KEY`):
платно, но это нормальный договорный сервис.

### Звуки и музыка

Своей звуковой библиотеки в поставке нет — см. раздел «Звуковые эффекты»
выше. `sfx_library.py --fetch` качает только **CC0**; лицензии `NC` и `ND`
отсеиваются намеренно, потому что запрещают монетизацию и переработку.

Фоновая музыка подбирается из Internet Archive под Creative Commons и, если
задан ключ, из Jamendo. Проверяй условия конкретного трека, если ролик
коммерческий: под «Creative Commons» скрываются в том числе `NC`-варианты.

### Стоковые кадры

Pexels и Pixabay отдают материал под своими лицензиями — обе разрешают
коммерческое использование без атрибуции, но обе запрещают отдавать сам
материал дальше как самостоятельный товар. В смонтированном ролике это не
проблема.

## Если что-то пошло не так

- **«Python не найден»** — при установке Python не была отмечена галочка
  «Add python.exe to PATH». Переустанови с ней либо добавь путь вручную.
- **Поставил FFmpeg, а скрипт его не видит** — закрой окно и запусти заново:
  `PATH` обновляется только в новых окнах.
- **Генерация падает на тексте** — кончилась суточная квота Gemini. Добавь
  `GEMINI_API_KEY2` или подожди 15–20 минут.
- **Оверлеи выглядят простовато** — не встал Node.js или пакеты Remotion.
  Проверь `node --version` и запусти `Запустить.bat` ещё раз.
- **Ролик собрался молча, без музыки** — не нашлось ни одного источника.
  Ключ для этого не нужен: подложка качается из Internet Archive под
  Creative Commons и ложится в `music_library` насовсем (замерено на чистой
  копии — трек на 37 минут за 23 секунды). Значит, дело в сети или в правах
  на запись в папку программы. `JAMENDO_CLIENT_ID` лишь добавляет источник.
- **«channels.json испорчен»** сразу после копирования примера — файл
  сохранён «UTF-8 с BOM». Пересохрани без BOM; свежие версии программы такой
  файл читают сами.

Подробный журнал работы — файл `app.log` в папке проекта. Идёт ли прямо
сейчас задача, можно спросить перед перезапуском:

```
.venv\Scripts\python is_busy.py
```

## Для владельца: сборка раздачи и установщика

Этого раздела касается только автор программы. Самих скриптов
(`setup\dist_pack.ps1`, `setup\installer.iss`) в раздаче нет — они остаются
в рабочей копии: покупателю нечего пересобирать, а в них поимённо перечислены
рабочие каналы.

**Шаг 1 — собрать раздаваемую копию.**

```
powershell -ExecutionPolicy Bypass -File setup\dist_pack.ps1 -OutDir dist
```

Собирает копию по белому списку и проверяет её четырьмя проходами:

1. запрещённые имена файлов и папок;
2. **настоящие значения** из твоих `.env` и `settings.json` — сверяется
   содержимое каждого текстового файла сборки;
3. строки, похожие на ключ по форме (`AIza…`, `sk-…`, `AKIA…`);
4. имена каналов, ниши и каналы-образцы.

Проверки 1–3 при срабатывании удаляют папку и возвращают код 1. Проверка 4
только предупреждает и печатает список файлов: это не секреты, а данные
владельца, и решение по ним — твоё.

**Шаг 2 — скомпилировать установщик.**

```
"%LOCALAPPDATA%\Programs\Inno Setup 6\ISCC.exe" setup\installer.iss
```

На выходе `setup\Output\КонтентФабрика-Установка.exe` — один файл около 3 МБ.
Компилятор ставится через `winget install JRSoftware.InnoSetup` и живёт
именно в `%LOCALAPPDATA%`, а не в `Program Files`.

Установщик не несёт внутри Python, Node, FFmpeg и `node_modules` — иначе он
весил бы гигабайты и устаревал бы за сутки. Он кладёт программу, ярлыки и
запускает `setup.ps1`, а тот доставляет окружение на месте.

Ни один из скриптов ничего никуда не выкладывает.

Что намеренно не попадает в копию: `.env`, `.env.bak`, `.secrets/`,
`settings.json`, `veononstop_support.txt`, `used_media.json`, `app.log`,
`channels.json`, `scenes.json`, `scenes_audit.json`, `variants.json`, папки
каналов, `assets/`, `music_library/`, `.venv/`, `.git/`, `node_modules/`,
`setup\Output\`.
