# Контент-фабрика

Конвейер, который делает документальный YouTube-ролик почти целиком сам:
придумывает тему с оглядкой на то, что сейчас смотрят в нише, пишет сценарий,
озвучивает, подбирает видеоряд (стоки + сгенерированные ИИ кадры), ставит
субтитры и моушн-графику, накладывает цветокор и звук — и отдаёт готовый файл.

Работает окном на Windows: запустил, нажал, ждёшь.

---

## Коротко: что нужно, чтобы начать

| Что | Зачем | Обязательно? |
|---|---|---|
| Windows 10/11 | приложение открывается окном, пути и шрифты — виндовые | да |
| Python 3.10+ | весь конвейер | да |
| FFmpeg | склейка, звук, цветокор | да |
| Node.js 18+ | моушн-графика Remotion | нет, но заметно лучше с ним |
| Ключ Google Gemini | тексты: сценарий, сцены, SEO | да |
| Ключ Pexels | видеоряд из стоков | да |
| Остальные ключи | ИИ-видео, музыка, разбор ниши | нет, см. таблицу ниже |
| ~10 ГБ на диске | окружение Python (2 ГБ), Remotion (0.7 ГБ), сами ролики | да |

## Запуск

1. Распакуй папку куда угодно (лучше без пробелов и кириллицы в пути).
2. Двойной клик по **`Запустить.bat`**.

Дальше скрипт всё делает сам: проверяет Python, FFmpeg и Node, создаёт
отдельное окружение `.venv`, ставит зависимости, ставит пакеты Remotion,
создаёт `.env` и по одному спрашивает ключи. В конце открывается окно
приложения.

**Первый запуск долгий: 15–30 минут** — качается около 3 ГБ (одно только
распознавание речи тянет `torch`). Все следующие запуски — секунды: скрипт
видит, что всё уже стоит, и сразу открывает окно.

Чего ждать, если чего-то не хватает:

- нет Python или FFmpeg — скрипт напишет точную команду `winget` и
  остановится; это единственные два обязательных условия;
- нет Node.js — работать будет, но моушн-графику нарисует встроенный
  движок: проще и менее эффектно;
- не заданы ключи — окно откроется, но генерация упадёт с внятным
  сообщением, какого ключа не хватило.

Полезные флаги (из командной строки в папке проекта):

```
Запустить.bat -Reconfigure   # заново пройти мастер ключей
Запустить.bat -SkipLaunch    # только настроить окружение, окно не открывать
```

## Ключи

Мастер при первом запуске проведёт по этому же списку и подскажет ссылки.
Любой ключ можно вписать позже — руками в файл `.env` в папке проекта.

### Обязательные

| Ключ | Зачем | Где взять | Цена |
|---|---|---|---|
| `GEMINI_API_KEY` | тексты: черновик сценария, разбивка на сцены, поисковые запросы, SEO | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) | бесплатно |
| `PEXELS_API_KEY` | видео и фото для сцен | [pexels.com/api](https://www.pexels.com/api/) | бесплатно |

Без Gemini текст писать нечем и конвейер не стартует. Без источника картинки
нечем заполнять сцены. Формально Gemini заменяется на `AGNES_API_KEY`, а
Pexels — на связку `VEO_API_KEY` + `AGNES_API_KEY` (тогда весь видеоряд
генерируется ИИ), но самый дешёвый рабочий минимум — именно эти два.

**Про квоту Gemini.** Она считается на пару «проект + модель», а не на ключ, и
на бесплатном тарифе кончается быстро — примерно два десятка запросов в сутки.
Код умеет перебирать несколько ключей: допиши в `.env` строки
`GEMINI_API_KEY2=`, `GEMINI_API_KEY3=` и так далее — они подхватятся сами.
Так же устроены `VEO_API_KEY2...` и `AGNES_API_KEY2...`.

### Желательные

| Ключ | Что даёт | Без него | Цена |
|---|---|---|---|
| `PIXABAY_API_KEY` | второй сток | материал однообразнее, чаще повторы | бесплатно |
| `VEO_API_KEY` | ИИ-видео Veo и ИИ-картинки | только сток и оживление фото «Ken Burns» | платно, подписка [veononstop.org](https://veononstop.org) |
| `AGNES_API_KEY` | ИИ-картинки, запасной канал для текстов | картинки уйдут на Gemini, запасного канала не будет | платно |
| `YOUTUBE_API_KEY` | разбор ниши перед роликом: что в теме уже заходит | тему придётся придумывать вручную, без опоры на свежие данные | бесплатно |

### По желанию

| Ключ | Что даёт | Без него |
|---|---|---|
| `JAMENDO_CLIENT_ID` | фоновая музыка по лицензии | подбор музыки пропускается; можно указать свою папку в настройках |
| `AWS_ACCESS_KEY_ID` + `AWS_SECRET_ACCESS_KEY` | озвучка Amazon Polly | озвучивает бесплатный Edge TTS — большинству этого хватает |

## Сколько это стоит и сколько идёт

Оценки грубые: всё зависит от длины ролика и доли ИИ-кадров.

**Полностью бесплатный набор** (Gemini + Pexels + Edge TTS): ролик на 10–13
минут собирается примерно за **40–90 минут**. Денег — ноль. Видеоряд целиком
стоковый, поэтому кадр не всегда точно ложится на фразу.

**С ИИ-видео** (добавлен `VEO_API_KEY`): те же 10–13 минут собираются
**2–5 часов** — генерация видео идёт через очередь на стороне сервиса, и это
самое узкое место. Зато кадр соответствует тексту по построению, а не по
совпадению ключевого слова. Стоимость — по подписке сервиса.

Что занимает время, по убыванию: генерация ИИ-видео → распознавание речи для
субтитров → рендер моушн-графики → склейка ffmpeg.

Заметное ускорение: в `.env` поставить `VEO_FAST_MODE=1` (ИИ-видео только на
ключевые сцены, остальные ИИ-кадры оживляются локально) и `VEO_UPSCALE=0`
(черновик в 720p вместо апскейла до 1080p).

Есть ночной режим: приложение берёт задачу и ведёт её до утра само, не
начиная ролик, который заведомо не успеет закончить.

## Звуковые эффекты

В раздаче нет папки `assets/`: звуки в ней под чужой лицензией, передавать их
дальше нельзя. Своя библиотека собирается одной командой:

```
.venv\Scripts\python sfx_library.py --fetch
```

Качает подборку из коллекций Internet Archive под **CC0** (общественное
достояние: коммерческое использование без атрибуции, ключ не нужен).
Лицензии `NC` и `ND` намеренно не берутся — они запрещают монетизацию и
переработку, а на канале с рекламой это прямой риск.

Пока библиотеки нет, рендер обходится тремя синтезированными звуками: ролик
соберётся, но звуковой ряд будет однообразным.

## Каналы

Настройки канала — язык, тон, длительность, голос, палитра цветокора, стиль
субтитров, доля ИИ-кадров — живут в `channels.json`. В раздаче его нет: там
рабочие данные автора (темы, счётчики серий, заметки о конкурентах).

Рядом лежит `channels.example.json` — скопируй его в `channels.json` и
поправь под себя либо заведи канал прямо в окне приложения.

Каждый канал держит свой почерк намеренно: свои палитры монтажа, свой набор
звуков, свой шрифт субтитров. Иначе разные каналы выглядят одинаково, а
субтитры — самый заметный элемент на экране.

## Если что-то пошло не так

- **«Python не найден»** — при установке Python не была отмечена галочка
  «Add python.exe to PATH». Переустанови с ней либо добавь путь вручную.
- **Поставил FFmpeg, а скрипт его не видит** — закрой окно и запусти заново:
  `PATH` обновляется только в новых окнах.
- **Генерация падает на тексте** — кончилась суточная квота Gemini. Добавь
  `GEMINI_API_KEY2` или подожди 15–20 минут.
- **Оверлеи выглядят простовато** — не встал Node.js или пакеты Remotion.
  Проверь `node --version` и запусти `Запустить.bat` ещё раз.
- **Ролик собрался молча, без музыки** — не задан `JAMENDO_CLIENT_ID`.

Подробный журнал работы — файл `app.log` в папке проекта. Идёт ли прямо
сейчас задача, можно спросить перед перезапуском:

```
.venv\Scripts\python is_busy.py
```

## Что внутри

- `webapp.py` — окно приложения (pywebview), точка входа
- `core.py` — логика конвейера: тексты, поиск материала, ИИ-генерация
- `render.py` — сборка видео, звук, цветокор, субтитры
- `overlays.py` — моушн-графика: Remotion, с откатом на встроенный движок
- `channels.py` — профили каналов
- `autopilot.py`, `night_plan.py` — ночной режим
- `sfx_library.py` — сборка библиотеки звуков CC0
- `yt_research.py` — разбор ниши перед роликом
- `remotion/` — React-сцены оверлеев (собираются через npm)
- `setup/` — установщик и сборщик раздаваемой копии

## Для владельца: сборка раздаваемой копии

```
powershell -ExecutionPolicy Bypass -File setup\dist_pack.ps1 -Zip
```

Собирает копию по белому списку: только исходники, интерфейс, установщик и
документация. Затем проверяет её тремя проходами — по запрещённым именам, по
настоящим значениям из твоих `.env` и `settings.json`, и по форме строк,
похожих на ключи. Если сработает любая проверка, папка удаляется, а в отчёт
попадает имя переменной и файл — но не само значение.

Скрипт ничего никуда не выкладывает: на выходе папка и, по флагу `-Zip`,
архив рядом с ней.

Что намеренно не попадает в копию: `.env`, `.secrets/`, `settings.json`,
`veononstop_support.txt`, `used_media.json`, `app.log`, `channels.json`,
папки каналов (`abyss/`, `home-vault/`, `estoico-es/`), `assets/`,
`music_library/`, `.venv/`, `.git/`, `node_modules/`.
